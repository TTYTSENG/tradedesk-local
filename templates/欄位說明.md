# CSV 欄位說明

使用英文欄名；* 表示必填。所有示例資料均為虛構。

## products

| 欄名 | 中文說明 | 格式 |
|---|---|---|
| id | 產品ID * | id |
| name | 產品名稱 * | text |
| hs_code | HS Code * | 2–12 位數字，文字格式 |
| description | 產品說明 | text |
| advantage | 主要優勢 | text |
| moq | 最低訂購量 | text |
| lead_time | 交期 | text |
| incoterm | 貿易條件 | text |
| sku | 成品料號／SKU | text |
| model | 型號／版本 | text |
| specification | 成品規格 | text |
| material | 主要材質 | text |
| unit | 成品計量單位 | text |
| net_weight_kg | 單件淨重 kg | 非負數字，可留白 |
| packaging_type | 包裝方式 | text |
| packaging_notes | 內包裝／外箱說明 | text |
| units_per_carton | 每箱成品數量 | 正整數 |
| carton_length_cm | 外箱長 cm | 正數，可填小數 |
| carton_width_cm | 外箱寬 cm | 正數，可填小數 |
| carton_height_cm | 外箱高 cm | 正數，可填小數 |
| carton_count | 出貨箱數 | 正整數 |
| gross_weight_per_carton_kg | 每箱毛重 kg | 非負數字，可留白 |

## markets

| 欄名 | 中文說明 | 格式 |
|---|---|---|
| id | 市場紀錄ID * | id |
| product_id | 產品ID * | 既有產品ID |
| country | 國家／市場 * | text |
| year | 年度 * | year |

## drafts

| 欄名 | 中文說明 | 格式 |
|---|---|---|
| id | 草稿ID * | id |

| language | 語言 * | en／zh |

| body | 內文 * | text |
| status | 信件狀態 * | 草稿／已手動寄出 |

## bom

| 欄名 | 中文說明 | 格式 |
|---|---|---|
| id | BOM 明細ID * | id |
| product_id | 成品產品ID * | 既有產品ID |
| line_no | 項次 * | 正整數 |
| component_code | 材料／零件料號 * | text |
| component_name | 材料／零件名稱 * | text |
| specification | 材料規格／尺寸 | text |
| material | 材質 | text |
| quantity | 每一成品用量 * | 正數，可填小數 |
| unit | 材料計量單位 * | text |
| waste_pct | 額外耗損率 % | 非負數字，可留白 |
| unit_cost | 材料單價 | 非負數字，可留白 |
| currency | 單價幣別 ISO 代碼 | 三位英文字母，如 USD／TWD；有單價必填 |
| supplier | 供應商 | text |
| notes | 備註 | text |

## ppap_projects

| 欄名 | 中文說明 | 格式 |
|---|---|---|
| id | 開發專案ID * | id |
| company_id | 客戶公司ID * | 既有公司ID |
| product_id | 產品ID * | 既有產品ID |
| name | 新產品開發專案名稱 * | text |
| part_number | 客戶零件料號 | text |
| drawing_revision | 圖面／工程版本 | text |
| submission_reason | 提交原因／變更原因 | text |
| submission_level | 客戶指定提交等級 * | 1／2／3／4／5 |
| customer_requirements | 客戶特定要求與約定 | text |
| owner | 專案負責人 | text |
| start_date | 開始日期 | YYYY-MM-DD |
| target_date | 目標提交日期 | YYYY-MM-DD |
| stage | 開發階段 * | 需求確認／設計與製程開發／試產驗證／文件審核／提交客戶／客戶核准／暫准／限量／退件改善／暫停 |

| approved_by | 客戶核准人 | text |
| approval_reference | PSW／客戶核准紀錄編號 | text |
| interim_limits | 暫准數量／有效期限／限制 | text |
| next_action | 下一步／改善事項 | text |
| notes | 備註 | text |

## ppap_items

| 欄名 | 中文說明 | 格式 |
|---|---|---|
| id | PPAP 項目ID * | id |
| project_id | 開發專案ID * | text |
| element_no | PPAP 項次 1–18 * | 正整數 |
| requirement | 提交／留存適用性 * | 待確認／需提交／留存備查／不適用 |
| status | 文件作業狀態 * | 未開始／準備中／待審核／已完成／需補件 |
| owner | 項目負責人 | text |
| due_date | 預定完成日期 | YYYY-MM-DD |
| document_reference | 文件／報告編號 | text |
| document_revision | 文件版本 | text |
| summary | 文件／試驗結果摘要 | text |
| review_result | 內部審核結果 * | 待確認／通過／不通過 |
| reviewed_by | 內部審核人 | text |
| review_date | 內部審核日期 | YYYY-MM-DD |
| waiver_reason | 不適用理由與客戶同意依據 | text |
| notes | 改善／備註 | text |
