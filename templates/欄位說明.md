# CSV 欄位說明

使用英文欄名；* 表示必填。所有示例資料均為虛構。

## products

| 欄名 | 中文說明 | 格式 |
|---|---|---|
| id | 產品ID * | id |
| name | 產品名稱 * | text |
| hs_code | HS Code * | 2–12 位數字，文字格式 |
| description | 產品說明 | text |
| advantage | 主要優勢 | text |
| moq | 最低訂購量 | text |
| lead_time | 交期 | text |
| incoterm | 貿易條件 | text |

## markets

| 欄名 | 中文說明 | 格式 |
|---|---|---|
| id | 市場紀錄ID * | id |
| product_id | 產品ID * | 既有產品ID |
| country | 國家／市場 * | text |
| year | 年度 * | year |
| import_usd | 進口額 USD * | USD 非負數字，不含逗號 |
| source_url | 資料來源網址 | url |
| notes | 備註 | text |

## companies

| 欄名 | 中文說明 | 格式 |
|---|---|---|
| id | 公司ID * | id |
| product_id | 產品ID * | 既有產品ID |
| name | 公司名稱 * | text |
| country | 國家／市場 * | text |
| website | 公司網站 | url |
| contact_name | 主要聯絡人 | text |
| contact_role | 聯絡人職稱 | text |
| email | 公開商務 Email | email |
| linkedin | LinkedIn 網址 | url |
| source_url | 聯絡資料來源網址 | url |
| stage | 業務階段 * | 待開發／已聯繫／已回覆／洽談中／已成交／暫停 |
| next_followup | 下次跟進日期 | YYYY-MM-DD |
| notes | 備註 | text |

## drafts

| 欄名 | 中文說明 | 格式 |
|---|---|---|
| id | 草稿ID * | id |
| company_id | 公司ID * | 既有公司ID |
| language | 語言 * | en／zh |
| subject | 主旨 * | text |
| body | 內文 * | text |
| status | 信件狀態 * | 草稿／已手動寄出 |
| created_at | 建立日期 * | YYYY-MM-DD |
| check_audience | 已確認對象與職務 | 是／否 |
| check_product | 已確認產品與市場適配 | 是／否 |
| check_benefit | 已說明具體利益 | 是／否 |
| check_proof | 已核實規格與佐證 | 是／否 |
| check_cta | 已有明確行動邀請 | 是／否 |
| check_contact | 已填妥寄件聯絡資訊 | 是／否 |
| check_review | 已人工檢查語言與附件 | 是／否 |

## activities

| 欄名 | 中文說明 | 格式 |
|---|---|---|
| id | 紀錄ID * | id |
| company_id | 公司ID * | 既有公司ID |
| date | 紀錄日期 * | YYYY-MM-DD |
| type | 紀錄類型 * | 開發信／回覆／電話／會議／跟進／備註 |
| subject | 信件／會議主旨 | text |
| summary | 往來內容摘要 * | text |
| reply | 對方信件原文 | text |
| body | 我方信件原文 | text |
| requests | 客戶需求／問題 | text |
| commitments | 我方承諾 | text |
| action_items | 下一步／待辦 | text |
| next_followup | 建議跟進日期 | YYYY-MM-DD |
